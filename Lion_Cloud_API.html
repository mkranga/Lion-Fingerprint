Cloud Sync Attendance API REST API

Overview

This documentation explains how to retrieve attendance records from the Lion Fingerprint cloud server.

Important: The endpoint uses Sync.php with a capital S. The URL is case-sensitive. 
https://lionts.com.lk/cloud/api/Sync.php

Cloud Architecture

  • Device Synchronization — Devices push attendance data, profiles and settings.
  • Data Storage — Cloud database stores synchronized data.
  • API Endpoint — Single endpoint provides flexible data retrieval.

Get Attendance Logs

GET /cloud/api/Sync.php?duid=<device-id>&dt=<unix-timestamp>&type=<format-type>
Parameter Type Required Description
duidStringYesDevice Unique Identifier
dtIntegerYesUnix timestamp in seconds
typeIntegerYesResponse type (0,1,2,3)

Complete PHP Integration Example

<?php

$CLOUD_SERVER="https://lionts.com.lk";
$DEVICE_DUID="LION8045090804509";

$days=7;
$timestamp=time()-($days*86400);

$url=sprintf(
"%s/cloud/api/Sync.php?duid=%s&dt=%d&type=0",
$CLOUD_SERVER,
urlencode($DEVICE_DUID),
$timestamp
);

$response=file_get_contents($url);

if($response===false){
die("Failed to fetch attendance");
}

$records=json_decode($response,true);

foreach($records as $batch){
echo $batch['cdate'];
echo $batch['logdata'];
}

?>
