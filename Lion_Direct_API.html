Overview

This document explains communication with the Lion Fingerprint Machine over the local network.

Recommendation: Use lionfp.local only for discovery. Use the returned IP address for faster communication.

Quick Start

Step 1 — Discover Device

GET http://lionfp.local/statistics

Step 2 — Login

POST http://192.168.1.100/login

{
 "username":"admin",
 "password":"admin"
}

Step 3 — Get Attendance

curl -X POST "http://192.168.1.100/attendance" \
-H "authkey: YOUR_AUTH_KEY"
